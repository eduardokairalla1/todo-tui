# todo

A simple terminal-based todo application.
This is a small project created for learning Go, exploring TUI development with Bubbletea and data persistence. Nothing fancy here.

## Requirements

- Go 1.25+

## Install dependencies

```bash
go mod download
```

## Running

```bash
./scripts/run
```

## Building

```bash
./scripts/build
```

The binary will be created at `./build/todo-tui`.
